## 🎯 Sobre o Projeto

Este projeto dá vida à ideia de **"Páginas de Turismo sobre a cidade de Busan"**, concebida como uma experiência web visual e informativa para viajantes que desejam explorar o litoral sul-coreano.

### 🌟 Destaques & Funcionalidades:
1. **Atrações Turísticas com Filtro Dinâmico:**
   - Filtro em tempo real por categorias (*Praias & Litoral*, *Templos & História*, *Mercados & Vida Urbana*, *Parques & Mirantes*).
   - Modal interativo com ficha detalhada de cada atração.
2. **Gastronomia Local de Busan:**
   - Pratos icônicos com nomes em hangul (*Dwaeji Gukbap*, *Ssiat Hotteok*, *Milmyeon*, *Frutos do mar vivos*).
3. **Roteiro Planejado de 3 Dias:**
   - Linha do tempo visual dia a dia conectando os melhores bairros e pontos turísticos.
4. **Calculadora & Conversor de Moeda Interativo:**
   - Conversão instantânea de Won sul-coreano (KRW ₩) para Real (BRL R$).
   - Estimador dinâmico de orçamento diário (Mochileiro, Moderado, Luxo).
5. **Guia Prático do Viajante:**
   - Dicas sobre transporte (KTX de Seul, Cartão T-Money), melhores épocas para visita, aplicativos de navegação e idioma.
6. **Design & Acessibilidade:**
   - Alternador de Modo Escuro / Claro com persistência em `localStorage`.
   - Menu mobile fluido e responsivo.
   - Tipografia refinada via Google Fonts (*Playfair Display* e *Plus Jakarta Sans*).

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica com `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` e atributos de acessibilidade ARIA.
- **CSS3:** Layouts avançados com CSS Grid e Flexbox, variáveis customizadas (`:root` e `[data-theme="dark"]`), transições suaves e tipografia fluida.
- **JavaScript (Vanilla ES6+):** Manipulação de DOM sem dependências externas, cálculo de conversão monetária, controle de abas/filtros e gerenciamento de estado local.

## 🚀 Como Executar Localmente

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
git clone https://github.com/jvcv2807/busan-turismo.git
cd busan-turismo
# Abra diretamente no seu navegador favorito:
xdg-open index.html # ou no Windows: start index.html / macOS: open index.html
```
